# Memory Hierarchy — Registers, Caches, HBM, GDDR, and Why Bandwidth Wins

A walk through every level of the NVIDIA GPU memory hierarchy across families — register files, shared memory, L1/L2 caches, HBM2e/3/3e, GDDR6/6X/7, LPDDR5x unified memory, and Hopper's TMA. Numbers that tell you what your GPU can actually do, plus an interactive decode-speed estimator.
